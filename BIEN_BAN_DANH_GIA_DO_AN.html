HƯỚNG DẪN SỬA NHANH (QUICK FIX) ĐỂ ĐẠT ĐIỂM TỐI ĐA 10.0 / 10.0:
1. Thêm Auth Guard tại trang Checkout (page/customer/checkout.html):
Thêm đoạn script sau vào đầu thẻ <body> của file checkout.html: 
<script>
  const user = sessionStorage.getItem('hds_auth_user');
  if (!user) {
    alert('Vui lòng đăng nhập trước khi tiến hành thanh toán đơn hàng!');
    window.location.href = '../auth/login.html?redirect=checkout';
  }
</script>
2. Đồng bộ đơn mới đặt vào Lịch sử đơn hàng (page/customer/customer.js):
Trong hàm getOrders() của file customer.js (khoảng dòng 291), thêm đoạn đọc đơn mới: 
const lastOrder = readJSON(LAST_ORDER_KEY, null);
if (lastOrder && !DEMO_ORDERS.some(o => o.code === lastOrder.code)) {
  orders.unshift({
    code: lastOrder.code,
    status: 'shipping',
    statusLabel: 'Đang xử lý',
    date: formatDate(lastOrder.date),
    items: lastOrder.items.map(it => ({ id: it.id, quantity: it.quantity })),
    address: lastOrder.address
  });
}
